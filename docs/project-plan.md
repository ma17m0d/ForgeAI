## 4. Working Agreement

* Use GitHub Issues to track tasks and problems.
* Use descriptive branches for new features.
* Commit related changes with clear messages.
* Review changes before merging them into the main branch.
* Pull the latest shared changes before starting new work.
* Do not commit passwords, credentials, or private student data.
