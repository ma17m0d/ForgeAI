# ForgeAI

## Project Overview

ForgeAI is an intelligent student team formation and academic project collaboration system. It aims to help students and instructors form balanced project teams based on skills, interests, availability, and project requirements.

## Problem Statement

Forming student project teams manually can be time-consuming and may result in teams with unbalanced skills or insufficient coverage of project requirements. ForgeAI aims to support this process through structured student profiles and team recommendations.

## Project Objectives

* Create and manage student profiles.
* Record student skills, interests, and availability.
* Support team formation based on project requirements.
* Evaluate skill coverage and team balance.
* Support project task and progress tracking.

## Proposed Technologies

* Programming language: Java
* User interface: Java Swing
* Database: SQLite
* Database connectivity: JDBC
* IDE: Apache NetBeans
* Version control and collaboration: Git and GitHub
* Testing: JUnit

## Main Features

1. Student profile management
2. Project requirements management
3. Team recommendation and skill coverage
4. Project task and progress tracking
